# How to use sail-riscv to execute an ELF file

* Check out `https://github.com/GaloisInc/sail-riscv` with branch `vr-scatter-termination-debug`
* Check out `https://github.com/GaloisInc/sail` with branch `jln-riscv-tests`
* Check out `https://github.com/jn80842/sail-riscv` with branch `master`. This is where the SPIKE tests are checked in.

Within sail-riscv, build the lean model with:

`cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo -DSAIL_MODULES="Zca;Zicbom_insts;Zicboz;Zicsr_insts;Zkr;postlude" && cmake --build build --target generated_lean_executable_rv64d`

To execute an ELF file, from within `sail/test/lean-riscv`, run

```
LEAN_BACKTRACE=1 lake exec run-riscv-lean -- path/to/file.elf
```
